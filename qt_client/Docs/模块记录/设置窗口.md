# 模块记录：设置窗口

## 类关系

```
MainWindow::openSettings()
 └─ SettingsDialog（QDialog，无标题栏，760x520）
      ├─ 左：#settingsSidebar
      │    ├─ #settingsNavButton × N（每个分类一个，互斥选中）
      │    └─ #settingsLogoutButton（“登出”，最底部）
      └─ 右：标题（当前分类名）+ × 关闭 + QStackedWidget
           ├─ AccountSettingsPage   账户：用户名、邮箱（可编辑）、UID（只读）
           └─ BakaSettingsPage      Baka：音量滑块、双击 LOGO 播放的滑动开关
```

对应 web 端的 `.settings-window`。web 端还有外观、系统、语言三个分类，客户端没做；
文件管理页两边都不做（web 端的已删）。

## 关键 API

| 类 | 成员 | 说明 |
|---|---|---|
| `SettingsDialog` | 构造 `(username, uid, email, SoundPlayer*)` | 每次打开时新建，关掉即销毁 |
| `SettingsDialog` | `exec()` 返回 `SettingsDialog::Logout` | 用户点了“登出”；× 关闭返回 `Rejected` |
| `SettingsDialog` | 信号 `nameChangeRequested(name)` / `emailChangeRequested(email)` | 账户页点了“保存”，原样转出来 |
| `SettingsDialog` | `setProfile(username, email)` / `showProfileError(msg)` | 把修改结果回填给账户页 |
| `ChatClient` | 槽 `changeName(name)` / `changeEmail(email)` | 发 `change_name` / `set_email` |
| `ChatClient` | 信号 `profileChanged()` / `profileChangeFailed(msg)` | 按服务端回执判断；成功时 `username()` / `email()` 已是新值 |
| `SoundPlayer` | `volume()` / `setVolume(0~100)` | 提示音音量，改动立刻写进 `QSettings` 的 `baka/volume` |
| `SoundPlayer` | `playOnLogo()` / `setPlayOnLogo(bool)` | 双击 logo 是否播放，存在 `baka/playOnLogo` |
| `ChatClient` | `email()` | 登录成功时服务端返回的邮箱，没绑定为空 |

## 调用流程

```
点账号栏的设置按钮 → ContactPanel::settingsClicked → MainWindow::openSettings
  → SettingsDialog::exec()
      点“登出”   → 返回 Logout → ChatClient::logout → loggedOut(false) → 回登录窗口（见 网络出口与登录.md）
      点 ×       → 返回 Rejected，什么都不做
      被顶下线   → loggedOut 连到 dialog.reject，设置窗口先关掉，再弹下线通知
拖音量滑块 → SoundPlayer::setVolume（实时生效 + 保存）；松手 → playBaka 试听一声
点开关     → SoundPlayer::setPlayOnLogo（保存）
双击 logo  → MainWindow 先看 playOnLogo()，开着才 playBaka

改昵称（改邮箱同理，换成 emailChangeRequested / changeEmail / set_email）
  点“编辑” → 该行换成输入框 + 保存 + 取消
  点“保存” → AccountSettingsPage::nameChangeRequested → SettingsDialog 转发
           → MainWindow 里连到 ChatClient::changeName → 发 change_name
  ← system "Name updated successfully. Your new name is [x]."
           → ChatClient 更新 m_username → profileChanged
           → SettingsDialog::setProfile（收起输入框，显示“已保存”）
           → ContactPanel::setAccount（左下角账号栏同步）
  ← system "Failed to ..." → profileChangeFailed → 行下面显示红字，输入框保留
```

## 核心逻辑说明

- **加一个设置分类只要一行**：在 `SettingsDialog` 构造函数里 `addPage(navLayout, 名字, 页面)`，
  导航按钮、切换、标题都由 `addPage` 处理。
- **设置页不碰网络**：账户页只发信号、显示结果，请求由 `MainWindow` 接到 `ChatClient`；
  Baka 页只和 `SoundPlayer` 打交道。
- **修改结果靠回执文本判断**：后端没有错误码，`ChatClient::handleProfileReply` 用正则匹配
  `Name updated successfully...` / `Email updated successfully...`，新值取自回执里方括号中的内容。
- **滑动开关是两张图**：`resources/icons/toggle_off.png` / `toggle_on.png`（按 web 端 `.toggle` 的尺寸和颜色生成），
  用可选中的 `QPushButton` + `QIcon` 的 On / Off 两态切换，没有滑动动画。
- **提示文字的颜色**：成功 / 失败共用一个标签，QSS 按 `error` 属性选色；属性变了 Qt 不会自动重算样式，
  所以 `showMessage` 里手动 `unpolish` / `polish` 一次。
- **设置项存在 `SoundPlayer` 里**：读写 `QSettings` 都收在它内部，设置页和 `MainWindow` 只调它的函数。
  这两项是本机设置，不跟账号走，退出登录不会清掉。
- **窗口可拖动**：无标题栏，所以 `SettingsDialog` 自己重写 `mousePressEvent` / `mouseMoveEvent` / `mouseReleaseEvent`
  （和 `LoginDialog` 同一套做法）：按下时记鼠标相对窗口左上角的偏移，移动时 `move` 到“鼠标位置 − 偏移”。
  按钮、输入框、滑块会自己吃掉鼠标事件，所以只有按在空白处（侧栏空白、标题、页面空白）才拖得动。

## 已知未做

- 改头像、改密码没做（web 端的改密码也只是界面，服务端没有改密码的接口）。
- 保存请求没有超时：断线时点保存，按钮会一直是不可点状态，要点“取消”或重开设置窗口。
- 外观（主题）、系统、语言三个分类没做。
- web 端 Baka 页的“发送消息时播放”“收到消息时播放”没做（客户端还没有收发消息）。
