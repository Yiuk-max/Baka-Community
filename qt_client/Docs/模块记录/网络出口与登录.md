# 模块记录：网络出口与登录（ChatClient）

## 类关系

```
main.cpp
 ├─ ChatClient（主线程，QObject）──── 唯一的网络出口
 │    ├─ QThread  m_netThread
 │    │    └─ WsCore（工作线程）── QWebSocket，只搬 QByteArray
 │    ├─ PacketCodec（Envelope <-> 4B 长度 + protobuf）
 │    ├─ QTimer 心跳（30s）
 │    └─ QTimer 认证超时（10s）
 ├─ LoginDialog ── LoginPage（表单 + 输入校验）
 ├─ AutoLoginDialog ── Spinner（本地有 token 时代替登录窗口先显示：logo + 转圈 + “登录...”）
 └─ MainWindow（只订阅 ChatClient 的信号）
```

页面不 include `WsCore.h`，只和 `ChatClient` 的信号/槽打交道。

## 关键 API（`src/net/ChatClient.h`）

| 成员 | 说明 |
|---|---|
| `start()` | 起网络线程并连接服务器 |
| `send(Envelope)` | 编码后投递到网络线程发送，后续所有业务请求都走它 |
| `login(identity, password)` | 纯数字按 `UID` 登录，否则按 `email` 登录 |
| `registerAccount(nickname, email, password)` | 注册；成功后**不**建立登录态 |
| `logout()` | 退出登录：发 `logout`、清账号和本地 token，发 `loggedOut(false)` |
| `uid()` / `username()` / `isConnected()` | 当前账号与连接状态 |
| `hasSavedToken()` | 本地是否存着 token（`main.cpp` 用它决定先显示哪个窗口） |
| 信号 `authStarted` / `loginSucceeded` / `registerSucceeded(uid, email)` / `authFailed(msg)` | 认证过程 |
| 信号 `loggedOut(kicked)` | 已回到未登录状态；`kicked = true` 是被顶下线 |
| 信号 `connected` / `disconnected(reason)` / `statusMessage` / `heartbeatAcked` | 连接状态 |
| 信号 `envelopeReceived(Envelope)` | 心跳、认证之外的所有消息，留给页面分发 |

## 调用流程

```
启动   main → ChatClient::start() → WsCore 连接
连上   onConnected → 心跳 → QSettings 有 token ? verify_token : 等用户操作
登录   LoginPage::loginRequested → LoginDialog 转发 → ChatClient::login
         → authStarted（按钮变“请稍候…”）→ 发 login
         ← login_success → 存 token → loginSucceeded → LoginDialog::accept → 显示 MainWindow
         ← system 文本   → authFailed(中文提示) → LoginPage::showError
注册   ChatClient::registerAccount → 发 register
         ← "Registration successful ... UID n or email." → registerSucceeded
         → LoginPage 切回登录表单并填好 UID，用户输入密码登录
超时   10s 没有回应 → authFailed("服务器响应超时，请重试")

自动登录（main.cpp）
  hasSavedToken() ? 显示 AutoLoginDialog : 直接显示 LoginDialog
  AutoLoginDialog::exec() 的三种结果：
    Accepted   ← loginSucceeded                    → 显示 MainWindow
    NeedLogin  ← authFailed（token 失效 / 超时）    → 显示 LoginDialog（错误提示已写在卡片上）
               ← disconnected（连不上服务器）
    Rejected   ← 用户 Alt+F4 / 从任务栏关闭         → 退出程序

退出登录（入口暂时搁置：界面上现在没有按钮会调 logout，等设置页做出来再接）
  ChatClient::logout
    → 发 logout（服务端保留连接，只是变回未登录）→ 清账号 + 清 token → loggedOut(false)
被顶下线
  ← system "…you have been kicked offline." → 清账号 + 清 token → loggedOut(true)
    （服务端发完这条就关连接）
两者共用 main.cpp 里 loggedOut 的处理（排队连接）：
  收起 MainWindow → kicked ? NoticeDialog（只有“我知道了”）: 跳过
  → LoginDialog::resetForm → LoginDialog::exec
      Accepted → 重新显示 MainWindow
      Rejected → 退出程序
断线后再登录
  ChatClient::sendAuth 发现没连上 → 请求先存着 → WsCore::reconnect → onConnected 里补发
```

`AutoLoginDialog` 没有标题栏也没有关闭按钮；`Spinner` 用 `QPainter` 画底圈和一段弧，
角度按经过的时间计算（0.8s 一圈），颜色由 `style.qss` 的 `qproperty-trackColor / qproperty-arcColor` 给。

## 核心逻辑说明

- **认证结果靠“在途状态”判断**：后端没有错误码，登录/注册失败只回 `system` 文本。
  未登录时服务端不会主动推送，所以 `m_pending != None` 期间收到的 `system` 就是本次请求的结果
  （`ChatClient::handleFrame` → `handleAuthReply`）。
- **token**：存在 `QSettings` 的 `auth/token`（Windows 下是注册表
  `HKCU\Software\Baka Community\Baka Community`）。`verify_token` 失败、退出登录、被顶下线都会删除本地 token。
- **`loggedOut` 用排队连接**：处理它时要 `exec()` 对话框，不能卡在 `ChatClient` 收帧的那次调用里。
  主窗口收起期间没有可见窗口，所以临时关掉 `quitOnLastWindowClosed`，对话框结束后再恢复。
- **被顶下线不自动重连**：token 已清，重连也登不上；等用户在登录窗口点登录时，
  `sendAuth` 才触发 `WsCore::reconnect`。
- **主窗口先创建后显示**：`login_success` 之后服务端会紧跟着推好友申请和离线消息，
  所以 `MainWindow` 在 `client.start()` 之前就建好并订阅 `envelopeReceived`，登录成功后才 `show()`。

## 已知未做

- 自动断线重连（现在只有“断线后点登录 / 注册”才会重连；已登录时掉线不会自己连回来；
  出错时 `disconnected` 信号可能发两次）。
- 退出登录时主窗口里的数据还没有需要清的（通讯录、消息做出来之后要在 `loggedOut` 里一并清空）。
- 登录后推来的好友申请、离线消息目前只在状态栏提示“暂未处理”。
