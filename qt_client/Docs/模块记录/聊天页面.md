# 模块记录：聊天页面（ChatPage + Composer）

## 类关系

```
MainWindow
 └─ ChatPage（QWidget，中间主区域）
      ├─ QLabel #chatHeader               顶部：当前会话名
      ├─ QScrollArea #chatScroll
      │    └─ QWidget #msgContainer（QVBoxLayout）
      │         ├─ QWidget #messageRow × N   每条消息一个 Widget
      │         │    ├─ QLabel（头像，36x36 圆形）
      │         │    └─ QWidget（内容列）
      │         │         ├─ #msgName / #msgSelfName + #msgTime
      │         │         ├─ #msgQuote（有回复引用时）
      │         │         └─ #msgText / #msgTextPending
      │         └─ [QSpacerItem stretch]  把消息顶到底部
      └─ Composer #composerOuter（底部输入框，外层只留边距 16/0/16/24）
           └─ QWidget #composerInner（圆角盒子，最小高 64，内边距左右 16）
                ├─ ComposerEdit #composerInput（QTextEdit 子类，拦截 Enter 键）
                └─ QToolButton #composerToolBtn（表情按钮，线条笑脸图标）
                     └─ EmojiPanel #emojiPanel（Qt::Popup 弹窗 420x360，第一次点击时才创建）
```

## 关键 API

| 类 | 成员 | 说明 |
|---|---|---|
| `ChatPage` | `openConversation(Contact, selfUid)` | 切换会话：清旧消息、改标题、拉首屏历史 |
| `ChatPage` | `clear()` | 退出登录时清空，输入框置灰 |
| `ChatPage` | `handleEnvelope(Envelope)` | MainWindow 路由进来的消息（history_response / 推送 / system 确认） |
| `Composer` | 信号 `messageSent(text)` | 用户按 Enter（没有发送按钮） |
| `EmojiPanel` | `popup(按钮全局矩形)` / 信号 `emojiSelected(emoji)` | 在按钮上方弹出；选中的表情插到输入框光标处，面板不关 |
| `Composer` | `setPlaceholder(text)` / `setEnabled(bool)` | 切换会话时更新提示文字 |
| `model/Message.h` | `struct Message` | 界面数据：messageId/senderName/content/timestamp/isSelf/isOptimistic/replyTo… |
| `util/TimeFormat.h` | `timeformat::toLocal(utc)` | UTC "YYYY-MM-DD HH:MM:SS" → 本地："HH:mm" 或 "MM/dd HH:mm" |

## 调用流程

```
点通讯录联系人
  → ContactPanel::contactSelected(contact)
  → MainWindow → ChatPage::openConversation(contact, uid)
       → 清旧 Widget、发 history_request{peer_id, before_id=0}

← history_response{peer_id, messages[], has_more}
  → ChatPage::handleEnvelope
       → 过滤已展示 id（m_messageIds），转成 Message 列表
       → appendMessages(msgs, prepend=false)
       → scrollToBottom（单次 QTimer::singleShot(0) 确保布局已算完）

用户滚动到顶（scrollBar.value < 60）且 hasMore && !loading
  → requestHistory(oldestId)   before_id = 当前最旧 id
← history_response → appendMessages(prepend=true) + 滚动补偿

用户输入消息 + Enter
  → Composer::messageSent(text)
  → 生成乐观消息（messageId 为负的临时 id），appendMessages，scrollToBottom
  → ChatClient::send(private_chat / group_chat)
← system "Message sent. Message ID: N"
  → m_optimisticLabels.firstKey() 对应的 QLabel objectName 改 "msgText"（视觉变实心）

实时推送 private_chat（对方发来）
  → 检查 sender_uid == conv.uid，去重（m_messageIds）
  → appendMessages + scrollToBottom

实时推送 Group_Chat（群聊，服务端广播含自己）
  → 检查 group_uid == conv.uid
  → 若 isSelf：升级乐观消息（取代 "Message sent" 路径），不重复添加
  → 否则：appendMessages + scrollToBottom
```

## 核心逻辑说明

- **乐观消息**：用 `m_nextTempId--`（从 -1 递减）生成负 id 占位，`m_optimisticLabels[tempId] = textLabel`；
  收到确认后改 `textLabel->setObjectName("msgText")`（QSS 颜色从灰变白）。
  群聊确认用 `Group_Chat` 推送而非 `system`，所以 `isSelf` 推送直接升级并跳过重复添加。
- **去重**：`m_messageIds`（QSet<int>）存所有已展示的真实 message_id；
  history/push 进来都先查 set，防止翻页补出来的消息和实时推送出现重复。
- **上拉加载滚动补偿**：prepend 时记下 `vbar->maximum()`，insertWidget 后用 `QTimer::singleShot(0)` 等布局重算，
  再把滚动条下移 `newMax - prevMax`，视觉上不跳动。
- **下滑到底**：同样用 `QTimer::singleShot(0)` 确保布局已算完再 `setValue(maximum())`。
- **收到别人的消息不强制滚到底**：推送进来时先看 `isAtBottom()`（滚动条离底部 ≤ 4px），
  本来就在底部才跟着滚；用户往上翻旧消息时保持原位，等他自己滑下来。自己发消息、首屏历史仍然滚到底。
- **IME 安全**：`ComposerEdit` 重写 `keyPressEvent`，只有 Enter/Return 且非 Shift 才触发发送；
  中文 IME 组字期间 Enter 由输入法内部消耗，不会到达 `keyPressEvent`，不会误发。
- **高度自适应**：Composer 监听文档布局的 `documentSizeChanged`，输入框高度 = 文档高度（最少一行、最高 160px），
  一行时由 64px 高的圆角盒子负责垂直居中；窗口变窄导致折行也会跟着长高。
- **表情面板**：尺寸配色对齐 web 端 `.emoji-panel`（420x360、8 列、选中分类 #5865f2）。9 个分类各一页，
  按钮在第一次切到该分类时才建（`fillPage`），避免一次建一千多个按钮。面板开着时再点表情按钮只关不重开
  （`mousePressEvent` 里设 `WA_NoMouseReplay`）。表情数据抄自 `frontend/src/data/emoji.js`，改那边要同步。

## 已知未做

- 真实头像（avatar_id 下载）：目前所有人都用 `defaultAvatar.png`。
- 未读数 / 未读角标：切换会话时不关注当前之外的推送。
- 删除消息（`delete_message`）：消息删除通知到来不处理。
- 文件消息显示（`is_file=true`）：目前当作纯文本显示原始字段。
- 频道（`Channel_Chat`）：入口在社区面板，本模块 `handleEnvelope` 已留 `Channel_Chat` 分支，待社区面板完成后对接。
- 消息分组（连续同人消息合并头像/名字）：暂时每条都显示头像和名字。
- 表情反应、消息编辑：后续阶段。
