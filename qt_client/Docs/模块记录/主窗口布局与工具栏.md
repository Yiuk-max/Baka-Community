# 模块记录：主窗口布局、工具栏与通讯录

## 类关系

```
MainWindow（QMainWindow）
 ├─ central（QWidget，QHBoxLayout，无边距无间距）
 │    ├─ ToolRail        左侧工具栏，固定宽 60
 │    │    ├─ QPushButton #railLogoButton（48x48，图标 34x34，顶部）
 │    │    ├─ QFrame #railDivider（分隔线）
 │    │    └─ QScrollArea #railCommunityArea（社区图标，每个社区一个 #railCommunityButton）
 │    ├─ ContactPanel    左侧通讯录，固定宽 240
 │    │    ├─ QLineEdit #contactSearch（搜索框）
 │    │    ├─ QLabel #contactHeading（“私信”）
 │    │    ├─ QListWidget #contactList（好友 + 群）
 │    │    └─ QWidget #accountBar（自己的头像 / 昵称 / 在线状态 / #accountSettingsButton 设置按钮）
 │    └─ QWidget #centerPage     中间页面，占满剩余宽度（占位）
 ├─ SoundPlayer（QObject）── QMediaPlayer + QAudioOutput
 └─ statusBar（心跳 / 连接状态）
```

尺寸和配色对齐 web 端 `frontend/reference-theme.css`（`--rail-w:60px`、`--sidebar-w:240px`、
`--rail-bg:#121214`、`--main-bg:#1a1a1e`）。

## 关键 API

| 类 | 成员 | 说明 |
|---|---|---|
| `ToolRail` | 信号 `homeClicked()` | 单击 logo；以后用来切回私聊 / 群聊页，目前没人接 |
| `ToolRail` | 信号 `logoDoubleClicked()` | 双击 logo |
| `ContactPanel` | 信号 `settingsClicked()` | 点了账号栏右侧的设置按钮；`MainWindow` 打开设置窗口（见 `设置窗口.md`） |
| `ToolRail` | `setCommunities(QList<Community>)` | 整份替换社区图标；传空列表即清空 |
| `ToolRail` | 信号 `communityClicked(Community)` | 点了某个社区图标；目前只在状态栏提示 |
| `ContactPanel` | `setContacts(QList<Contact>)` | 整份替换好友 / 群列表，保留原来的选中项 |
| `ContactPanel` | `setAccount(name, uid)` / `setOnline(bool)` / `clear()` | 底部账号栏；退出登录时清空 |
| `ContactPanel` | 信号 `contactSelected(Contact)` | 用户点了某个好友 / 群；目前只在状态栏提示 |
| `Contact` / `Community`（`model/Contact.h`） | 纯数据结构 | 控件只认它们，不认 protobuf |
| `avatar::`（`ui/Avatar.h`） | `rounded(path, size, radius)` / `roundedIcon(...)` | 把图片裁成圆形 / 圆角方形，按屏幕缩放比生成 |
| `SoundPlayer` | 槽 `playBaka()` | 从头播放一次内置 `baka.mp3`；音量和“双击 logo 是否播放”可在设置里改 |
| `assets::`（`ui/Assets.h`） | `logo()` `settingsIcon()` `defaultAvatar()` `defaultGroupAvatar()` `defaultCommunityAvatar()` `defaultBackground()` `bakaSoundUrl()` | 静态资源的 qrc 路径 |

## 调用流程

```
双击 logo → ToolRail::eventFilter 收到 MouseButtonDblClick → emit logoDoubleClicked
         → MainWindow 里先看 SoundPlayer::playOnLogo()，开着才调 playBaka → QMediaPlayer 播放 qrc:/audio/baka.mp3
```

和 web 端一致：单击 logo 是导航，**双击**才播放音效。

```
登录成功 → MainWindow 收到 loginSucceeded
         → ContactPanel::setAccount / setOnline(true)
         → requestLists()：发 show_contacts 和 show_communities
← contact_list_response   → MainWindow::handleEnvelope 转成 QList<Contact>   → ContactPanel::setContacts
← community_list_response → MainWindow::handleEnvelope 转成 QList<Community> → ToolRail::setCommunities
退出登录 / 被顶下线 → loggedOut → ContactPanel::clear + ToolRail::setCommunities({})
```

数据只走一个方向：`ChatClient` → `MainWindow`（protobuf 转成纯数据）→ 控件；控件不发请求、不认 protobuf。

## 核心逻辑说明

- **双击用事件过滤器**：`QPushButton` 没有双击信号，`ToolRail` 给按钮装 `installEventFilter`，
  只转发事件不拦截，所以单击的 `clicked` 照常发出。
- **QSS 背景**：自定义 `QWidget` 子类默认不画 QSS 背景，`ToolRail` 里设了 `Qt::WA_StyledBackground`。
- **mp3 依赖 Qt Multimedia**：`QSoundEffect` 只支持 wav，所以用 `QMediaPlayer`；
  `CMakeLists.txt` 把 `Multimedia` 列为必需组件。
- **静态资源**：图片从 `frontend/public` 缩小后放进 `resources/images/`
  （头像类 256px，背景 1280px；原图单张 1～2 MB，直接打进 exe 太大），音频原样复制到 `resources/audio/`。
  新增资源时：放文件 → `CMakeLists.txt` 的 `qt_add_resources` 加一行 → `Assets.h` 加一个函数。
- **通讯录用 `QListWidget`**：每行只有头像 + 名字，Qt 自带的列表项就够，没有上自定义 model / delegate。
  等要显示未读数、最后一条消息时再换。
- **搜索是本地过滤**：只在已加载的联系人里按名字匹配，不发请求。
- **选中项按 `(isGroup, uid)` 记**：好友 UID 和群 id 是两套编号可能相同；刷新列表或改搜索词后据此恢复选中。
  重建列表期间用 `QSignalBlocker` 挡住信号，避免把“程序重建”误报成“用户点了某人”。
- **头像目前全是默认图**：`avatar_id` 已经存进 `Contact` / `Community`，但还没做文件下载，
  所以好友、群、社区各用一张默认头像，`ContactPanel` 里只生成一次图标。
