# 模块记录：主页（HomePage）

登录后中间区域默认显示的页面，对应 web 端的好友页（`App.vue` 里 `activePage==='dm'` 的 `.friends-main`）。

## 类关系

```
MainWindow
 └─ QStackedWidget m_center（中间区域，同一时刻只显示一个）
      ├─ HomePage #homePage（主页，默认）
      │    ├─ QFrame #homeHeader（高 48）
      │    │    ├─ QLabel #homeTitle（“好友”）
      │    │    ├─ QFrame #homeHeaderDivider（竖线）
      │    │    └─ QPushButton #homeTab × 2（全部 / 待定，QButtonGroup 互斥）
      │    └─ QStackedWidget m_pages
      │         ├─ [0] QScrollArea #homeScroll → QWidget #homeContainer（边距 20/16/20/28）
      │         │       ├─ QLineEdit #homeSearch（搜索好友，高 40）
      │         │       ├─ QLabel #homeHeading（“全部 — N”） + QPushButton #homeLinkButton（＋ 新建群聊）
      │         │       ├─ 好友行 × N（QPushButton #homeRow） / QLabel #homeEmpty（没有找到好友）
      │         │       ├─ “群聊” #homeSubHeading + “你的群聊通讯录” #homeHint + 群聊行 × N
      │         │       └─ “社区” + “你加入的社区” + 社区行 × N / #homeEmpty（还没有加入社区。）
      │         └─ [1] QLabel #homeEmpty（待定页，空状态）
      └─ ChatPage（聊天页，见 聊天页面.md）
```

每一行（`makeRow`）是一个 `QPushButton #homeRow`，里面用布局放 头像 `QLabel` + 名字 `#homeRowName` + 可选的 `›` `#homeRowArrow`。

## 关键 API

| 类 | 成员 | 说明 |
|---|---|---|
| `HomePage` | `setContacts(QList<Contact>)` | 好友 + 群，整份替换；好友进“全部”，群进“群聊” |
| `HomePage` | `setCommunities(QList<Community>)` | 已加入的社区，整份替换 |
| `HomePage` | `clear()` | 退出登录时清空 |
| `HomePage` | 信号 `contactActivated(Contact)` | 点了好友 / 群的一行 |
| `HomePage` | 信号 `communityActivated(Community)` | 点了社区的一行 |
| `HomePage` | 信号 `createGroupClicked()` | 点了“＋ 新建群聊” |
| `MainWindow` | `openChat(Contact)` / `showHome()` | 中间区域在聊天页和主页之间切换 |
| `ContactPanel` | `select(Contact)` / `clearSelection()` | 让左侧通讯录的选中项和中间页面保持一致，都不发信号 |

## 调用流程

```
← contact_list_response   → MainWindow::handleEnvelope → ContactPanel::setContacts + HomePage::setContacts
← community_list_response → MainWindow::handleEnvelope → ToolRail::setCommunities + HomePage::setCommunities

主页点好友 / 群 → HomePage::contactActivated
               → MainWindow：ContactPanel::select(contact)（左侧跟着选中）→ openChat(contact)
               → ChatPage::openConversation + m_center 切到聊天页

左侧通讯录点联系人 → ContactPanel::contactSelected → MainWindow::openChat

单击工具栏 logo → ToolRail::homeClicked → MainWindow::showHome
               → ContactPanel::clearSelection + m_center 切回主页

退出登录 → HomePage::clear + m_center 切回主页
```

## 核心逻辑说明

- **整行是按钮**：行里的头像和文字都设了 `Qt::WA_TransparentForMouseEvents`，鼠标事件全落在按钮上，
  所以悬停变色（QSS `:hover`）和点击（`clicked`）都不用自己写事件处理。
- **搜索只过滤好友**：和 web 端一致，群聊和社区一直全部显示；“全部 — N”里的 N 是过滤后的好友数。
- **回主页要取消左侧选中**：`QListWidget` 再点已选中的行不会发 `currentRowChanged`，
  不取消的话回主页后就点不回原来那个会话了。
- **数据和通讯录是同一份**：`MainWindow` 把同一个 `QList<Contact>` 同时喂给 `ContactPanel` 和 `HomePage`，主页自己不发请求。
- **重建行**：列表变了或搜索词变了就整节删掉重建（`clearRows` 里先 `hide` 再 `deleteLater`）。行数是好友 / 群数量级，够用。

- “待定”页是独立的 `PendingPage`，已接好友申请和群聊 / 社区的入群申请审批（见 `菜单与协议接入.md`）；标签上用“待定 · N”代替红点。

- 好友行右侧的“发送消息”“更多”圆形按钮和右键菜单（设置备注 / 删除好友）没做。
- 群聊行的“N 位成员”、社区行的简介没显示（`contact_list_response` 里没有成员数）。
- 头像全是默认图。
