# Qt 客户端开发约束

> 本文是**强制约束**。任何一次改动都要先过一遍这份清单；与它冲突的写法一律不采用。
> 最后更新：仓库更名为 `Baka-Community` 时（`https://github.com/Yiuk-max/Baka-Community`）。

## 约束原文

Qt 客户端开发约束

1. 使用 C++17 + Qt 6 Widgets + CMake。
2. 优先使用纯 C++ 代码构建 UI，使用 QHBoxLayout、QVBoxLayout、QGridLayout 等布局管理器。
3. 不使用 Qt Designer 生成 .ui 文件，除非明确要求。
4. QSS 仅用于颜色、字体、边框、圆角、悬停状态等视觉样式，不允许用大量 QSS 代替正常的界面布局。
5. 每个 UI 页面独立封装为 QWidget 子类。
6. 控件命名清晰，避免过度封装和不必要的设计模式。
7. 禁止生成巨型类和巨型源文件，保持模块职责清晰。
8. 使用 Qt 原生 Signal / Slot 机制处理组件间通信。
9. 每完成一个模块，提供类关系、关键 API 说明、调用流程和核心代码讲解。
10. 不得为了追求代码量少而牺牲可读性，也不得引入当前阶段不需要的复杂架构。

## 工程里的落地方式（对照说明，便于自查）

| 约束 | 当前做法 | 位置 |
|---|---|---|
| 1. C++17 + Widgets + CMake | `CMAKE_CXX_STANDARD 17`；`find_package(Qt6 ... Core Gui Widgets Network WebSockets)` | `CMakeLists.txt` |
| 2. 纯 C++ 建 UI + 布局管理器 | 只用 `QHBoxLayout/QVBoxLayout/QGridLayout/QSplitter` 组装，不用绝对坐标 | `src/ui/**` |
| 3. 不用 .ui | 未启用 `AUTOUIC`，工程里不存在 `.ui` 文件 | `CMakeLists.txt` |
| 4. QSS 只做视觉 | QSS 集中在一个 `resources/style.qss`（后续新增），只写颜色/字体/边框/圆角/`:hover`，**不写 position/size/间距** | 后续 |
| 5. 每页一个 QWidget 子类 | `LoginPage`、`ChatPage`（会话列表 / 消息区 / 成员区各自独立 Widget） | `src/ui/**` |
| 6. 命名清晰、不过度封装 | 类名即职责（`ConversationListWidget`、`MessageView`、`Composer`）；不做无意义的 `ManagerFactoryProvider` 层 | 全局 |
| 7. 不做巨型类/巨型文件 | 单个 `.cpp` 目标 ≤ 400 行，超过就按职责拆（如 `MessageRowWidget` 从 `MessageView` 拆出） | 全局 |
| 8. 原生 Signal/Slot | 网络层发 `Envelope` 信号，页面按需 connect；不用自定义事件总线 | `src/net/**`、`src/ui/**` |
| 9. 每模块交付说明 | 每个模块完成后在 `Docs/模块记录/` 写：类关系图（ASCII）、关键 API、调用流程、核心代码片段 | `Docs/模块记录/**` |
| 10. 可读性 / 不过度设计 | 不引入 MVC/MVVM 框架、不搞 DI 容器、不加当前用不到的抽象层 | 全局 |

### 需要特别避免的具体行为

- ❌ 用 `setFixedSize` / `move` / `setGeometry` 拼界面（约束 2、4）；
- ❌ 把颜色、圆角、hover 写成 `setStyleSheet` 散落在各个类里（约束 4，应集中到 `style.qss` 或统一的主题常量）；
- ❌ 一个 `MainWindow.cpp` 里塞上会话列表 + 消息渲染 + 输入框 + 设置弹窗（约束 5、7）；
- ❌ 页面对网络层直接 `#include "WsClient.h"` 到处调用（约束 8，应由一个信号出口统一分发）；
- ❌ 为“以后可能要扩展”提前抽接口/工厂/插件机制（约束 10）。

### 交付检查清单（每次提交前）

- [ ] 新增代码是否为 C++17 语法（无 C++20 独有特性）
- [ ] 是否新增了 `.ui` 文件
- [ ] 界面是否全部由布局管理器组装
- [ ] QSS 是否只含视觉属性
- [ ] 每个页面/对话框是否独立 `QWidget` 子类
- [ ] 是否有单文件超过 400 行
- [ ] 组件间通信是否走 Signal/Slot
- [ ] 模块说明是否记录（类关系 / API / 流程 / 核心代码）
